# Périmètre des preuves

## Origine et date

Les études de cas ont été synthétisées le **7 octobre 2026** à partir de documentation privée de reprise, contrats métier, états de projet, descriptions d'architecture et preuves datées. Un accès en lecture aux serveurs a corroboré la présence des projets et de leurs services au moment de l'inspection.

Les tests historiques cités par la documentation n'ont pas été rejoués sur les systèmes privés pour fabriquer ce portfolio. La disponibilité d'un service a été distinguée de la validation d'une fonction.

## Ce qui est public et vérifiable

- Les décisions et limites décrites dans les études de cas.
- Le code indépendant, la table de décision et les tests du démonstrateur.
- Les contrôles automatiques exécutés sur ce démonstrateur, visibles dans son dépôt.

## Ce qui reste privé

Sources applicatives, documents internes, données clients, pièces fournisseurs, configurations, accès, hôtes, chemins de production et résultats financiers. Les études publiques ne constituent pas un accès à ces éléments ni une autorisation de redistribution.

## Lecture des résultats

« Déployé » et « validé métier » sont distingués. Les modules en recette, données manquantes, tests simulés et extensions locales sont explicitement identifiés. Aucun pourcentage de gain, chiffre de revenus, effectif managé ou SLA n'est déduit de la seule présence de code ou de tests.

Le démonstrateur public utilise **exclusivement des données fictives** et un contrat pédagogique propre ; il n'est pas une extraction des règles ou du code de production.
